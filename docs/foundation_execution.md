# Execution notes for the foundation experiment

The source-specific endpoint is dispatched directly from frozen discovery fits
and the frozen one-occurrence-per-duplicate-group samples. It need not wait for
the slower, secondary pooled-token tests. Sample keys are checked against the
geometric analysis, and the full positive partner membership is retained.

Uniform conditional permutations are generated by grouping movable strata of
equal size and independently permuting each row. Homogeneous strata remain
fixed. This preserves the conditional null, replicate count and endpoint, but
changes the seeded Monte Carlo realization relative to the original scalar
generator. It is an execution optimization, not a change in hypothesis or an
opportunity to select a favorable random seed. Both the primary source endpoint
and secondary geometry test record their code and frozen sample provenance.

Dictionary pair plots use every pair within the 2,048-feature discovery screen.
They do not claim to identify the global closest or most co-occurring pair among
all 65,536 dictionary entries. Token/document intersections are computed exactly
within this declared universe, without inferring zeros from absent graph edges.
The pair atlas uses both data splits and is descriptive; it is not an additional
held-out confirmation test. Decoder participation covers the complete dictionary.

Per-PC reconstruction R-squared uses native evaluation residual variance about
the evaluation mean as its denominator, in the discovery-fitted full PCA basis.
This differs from uncentered relative reconstruction error and from alignment
of decoder directions with high-variance PCs.
