# Project overview

SAE Feature Atlas turns corpus texts, token metadata, stored SAE activations and sampled residual vectors into population-explicit statistics, decoded evidence, supported coactivation, decoder geometry, qualified bimodality diagnostics and feature cards.

The product is the reusable Python library and CLI. Experiment-specific runners and findings live in [Model Behavior Research](https://github.com/serafim-tkachenko/model-behavior-research). Descriptive outputs do not establish causal control or automatic semantic interpretation.
