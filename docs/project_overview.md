# Project overview

SAE Feature Atlas is a descriptive SAE-analysis workflow. It turns corpus texts, token metadata, stored SAE activations, and sampled residual vectors into population-explicit feature statistics, decoded context evidence, supported coactivation, decoder geometry, qualified bimodality diagnostics, and feature cards.

The project does not currently claim causal control, automatic semantic interpretation, semantic PCA axes, or confirmed activation-dependent semantic regimes. Its active research direction is to test whether activation magnitude conditions a latent's contextual or coactivation structure using robust regime inference, matched controls, null baselines, held-out evidence, and sensitivity to top-k censoring.
